# WP V26 盘中拥挤确认数据可行性协议

## 1. 研究问题

V26 只回答一个数据问题：

> 在不读取任何 T+1 收益结果的前提下，是否存在覆盖正式三年样本期、在
> 14:20-14:50 当时真实可见、且不同于既有日线/5 分钟价量因子的盘中拥挤确认数据？

本阶段不是盈利回测。只有数据来源通过本协议，才允许进入后续全量构建和模型预注册。

## 2. 为什么不能继续重组旧因子

V9、V16、V22、V24 已经使用或检验过：

- 个股日线与 5 分钟价量；
- 大盘状态；
- 申万一级行业收益、广度和相对强度；
- 同日同槽横截面排序；
- 多种旧因子重加权。

V24 诊断没有找到稳定、具有足够经济幅度的同槽排序信号。因此 V26 不允许把上述
旧输入换一个权重后再次命名为新突破。

## 3. 预注册数据来源与固定优先级

### A. 首选：盘中注意力/拥挤数据

1. Tushare `ths_hot`，仅使用 `is_new=N` 的历史快照；
2. Tushare `dc_hot`，仅使用 `is_new=N` 的历史快照。

必须使用 `rank_time` 判断数据在信号时点是否已经存在。盘后快照、22:30 最新榜、
无法解析时间的记录均禁止进入研究。

### B. 固定备选：申万 L2/L3 同群指数

仅当 A 类没有任何一个来源通过覆盖门槛时，才允许启用 B 类：

1. `index_classify` 获取 SW2021 L2/L3 已发布指数；
2. `index_member_all` 的 `in_date/out_date` 恢复历史成分；
3. `sw_mins` 获取 L2/L3 指数历史 5 分钟行情。

这是细行业同群确认，不是既有申万 L1 广度的重复。选择 A 或 B 只允许依据数据覆盖，
禁止依据收益结果。

## 4. 探针日期

固定抽取正式样本期内八个交易日，覆盖每个年份和不同月份：

- 2023-08-25
- 2023-12-29
- 2024-03-15
- 2024-09-27
- 2025-01-15
- 2025-07-23
- 2026-01-15
- 2026-07-23

不得因为某日无数据而替换探针日期。

## 5. A 类通过门槛

每个来源分别判断。一个来源只有同时满足下列条件才通过：

1. 八个探针日期全部可查询；
2. 每日存在 `13:20:00-14:50:00` 的历史榜单快照；
3. 所选快照不少于 50 个唯一 A 股代码；
4. 快照内股票代码不重复；
5. `rank` 至少 95% 可解析且范围合法；
6. `rank_time` 与 `trade_date` 一致；
7. 快照时间不晚于 14:50。

只要 THS 或 DC 至少一个通过，后续 V26 固定采用 A 类。通过的来源全部保留，
未通过来源不进入特征集。

## 6. B 类通过门槛

B 类只有同时满足下列条件才通过：

1. SW2021 至少有 80 个已发布 L2 指数、150 个已发布 L3 指数；
2. 历史成分区间合法，无无法解释的倒置区间；
3. 八个探针日期各自至少恢复 3,500 个唯一股票；
4. 每个日期 L2/L3 分类完整率均不低于 95%；
5. 从已发布 L2/L3 指数按代码排序的固定分位点各抽四个指数；
6. 每个抽样指数在八个日期的 14:20-14:50 七个 5 分钟槽均有完整行情；
7. 所有分钟时间戳必须属于查询交易日且不晚于对应槽。

抽样指数由代码排序位置确定，不得人工挑选“表现好”的行业。

## 7. 固定选择规则

```text
if THS 或 DC 通过:
    selected_source_family = intraday_attention
elif SW L2/L3 通过:
    selected_source_family = fine_grained_industry_index
else:
    selected_source_family = null
    V26 停止，不做收益回测
```

本规则在探针运行前冻结。

## 8. 全量构建的第二道覆盖门槛

探针通过只授权构建，不授权模型。全量构建必须再次在
2023-07-27 至 2026-07-24 的全部 A 股交易日检查：

- 可用交易日覆盖率不低于 98%；
- 时间戳有效率 100%；
- 任何特征仅可使用该信号槽当时或更早的数据；
- 代码映射与历史成分区间有效；
- 不读取 `gross_return`、`net_return`、胜负标签或任何 T+1 真值。

未通过第二道门槛时，V26 仍直接停止。

## 9. 明确禁止

- 用盘后热榜回填盘中热榜；
- 使用 `is_new=Y` 的收盘后最终榜；
- 用未来行业成分替代历史成分；
- 根据收益选择 THS、DC、L2 或 L3；
- 在数据探针阶段读取任何收益标签；
- 覆盖不足后降低门槛或更换探针日期。

## 10. 决策

本协议只允许产生三种结论：

1. `intraday_attention` 通过，进入全量覆盖构建；
2. `fine_grained_industry_index` 通过，进入全量覆盖构建；
3. 无来源通过，V26 数据方向判负并停止。
