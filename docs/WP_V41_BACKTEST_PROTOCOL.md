# WP V41 回测与影子协议

## 1. 实验单元

实验单元是固定模型指纹、固定 14:00 决策、固定 14:05 影子入场和固定 T+1
收盘退出。任何参数、模型或时点变化都创建新实验，不能继承旧证据。

## 2. 历史区间

- 请求开始：`2026-05-01`
- 请求结束：`2026-07-31`
- 目标真值：每个 T 日对应下一 A 股交易日收盘

每个外层测试折只保留测试开始日前真值已知的数据。候选先冻结，再关联 T+1
真值。每个 `(trade_date, signal_slot, ts_code)` 必须唯一。

## 3. 两套样本

- **合格**：14:00 通过全部冻结门槛的全部股票，允许某日为 0。
- **观察**：每天 5 支硬可执行、但未完全合格的最近门槛样本。

两套 CSV、月度统计、累计统计和页面区域均分开。

## 4. 主要指标

- 已验证股票数和交易日数；
- 正净收益胜率及置信下界；
- 平均、中位和 10% 分位净收益；
- Profit Factor；
- 入场、退出和完整往返成交率；
- 等权日收益、复利累计收益和最大回撤；
- 35bp 与 50bp 压力测试。

未到期记录保持 pending，不得当成盈亏或静默删除。

## 5. 页面累计口径

每天先对当日同组股票净收益等权平均，得到“当日组合净收益”。当月总收益和历史
总收益再对完整验证日的组合净收益做复利。未全部验证的日期不进入累计收益。

旧 14:30/14:35 合同单独标记，只供审计，不与 V41 合并。

## 6. 未来影子

- 起始交易日：`2026-08-05`
- 最少交易日：150
- 最少候选日：50
- 最少已验证合格票：250
- 必须精确绑定同一 `model_fingerprint`
- 必须发生在模型训练完成之后

重训、改门槛或改执行合同后计数归零。
