# WP V40 回测与影子协议

## 1. 实验单元

实验单元是固定模型指纹、固定 14:30 决策、固定 14:35 参考入场和固定 T+1
收盘退出合同。任何参数或模型变化都创建新实验，不能继承旧证据。

## 2. 历史区间

- 请求开始：`2026-05-01`
- 请求结束：`2026-07-31`
- 实际日期：以上区间内全部 A 股交易日，首日为 `2026-05-06`
- 目标真值：每个 T 日对应的下一 A 股交易日收盘

2026-07-31 的目标日为 2026-08-03。该真值尚未到位时，报告状态必须为
`INCOMPLETE`，历史晋级门槛自动失败。

## 3. 严格样本外流程

对每个外层测试折：

1. 只保留测试开始日之前、真值已知的训练记录。
2. 基础评分使用已有不可变外层样本外预测。
3. 元模型使用 126 日训练、2 日净空、21 日校准。
4. 退出风险模型使用 252 日训练、2 日净空、42 日校准；保留共用模型至少
   5,000 条训练样本的硬门槛。
5. 固定 V40 门槛只在测试折上执行，不根据测试结果调整。
6. 测试折选择结果先冻结，再关联 T+1 真值。

每个 `(trade_date, signal_slot, ts_code)` 必须唯一。重复身份、缺失交易日、
缺失固定 5 支观察或合格与观察重叠，都会使回测标记为不完整。

## 4. 两套样本

### 合格候选

统计正式模型在 14:30 通过全部门槛的全部股票。允许某日为 0。

### 标准观察

统计每天 5 支硬可执行、但未完全合格的最近门槛样本。观察结果只用于判断门槛
是否有区分价值，不能并入合格候选收益。

两套 CSV、月度统计、累计统计和页面区域均分开。

## 5. 主要指标

- 已验证股票数和交易日数；
- 正净收益胜率；
- Wilson 胜率下界；
- 按交易日聚类 bootstrap 胜率下界；
- 平均和中位净收益；
- 按交易日聚类平均收益下界；
- 10% 收益分位；
- Profit Factor；
- 入场、退出和完整往返成交率；
- 等权日收益、累计收益和最大回撤；
- 35bp 与 50bp 压力测试。

统计只使用 `label_available=true` 的记录。未到期记录保持 pending，不得当作
亏损、盈利或从样本中静默删除。

## 6. 历史晋级门槛

合格候选必须同时满足：

- 完整日期、真值和观察队列；
- 至少 250 支样本；
- 胜率至少 55%；
- Wilson 胜率下界至少 52%；
- 按日聚类胜率下界至少 52%；
- 平均净收益至少 0.20%；
- 按日聚类平均收益下界不低于 0；
- Profit Factor 至少 1.20；
- 50bp 压力总收益为正。

历史通过不等于可盈利或可生产，只允许开始精确模型的未来影子验证。

## 7. 未来影子

- 起始交易日：`2026-08-03`
- 最少交易日：150
- 最少候选日：50
- 最少已验证合格候选：250
- 必须精确绑定同一 `model_fingerprint`
- 必须发生在模型训练完成之后

影子阶段继续检查历史门槛中的胜率、置信下界、收益、Profit Factor、成交率、
概率校准和 50bp 压力收益。重训后计数归零。
