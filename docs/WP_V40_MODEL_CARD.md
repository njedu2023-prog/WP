# WP V40 模型卡

## 用途

WP V40 在每个 A 股交易日 14:30 对主板可交易股票评分，输出全部固定门槛合格
候选和 5 支独立标准观察。它服务人工决策，不自动交易。

## 预测目标

主要目标是固定 14:35 参考入场、T+1 收盘退出、扣除 10bp 入场滑点和 25bp
往返成本后的 `net_return_pct > 0`。

辅助目标包括：

- 14:35 参考订单可成交；
- 入场后 T+1 可退出；
- 完整往返成交后的正净收益；
- 完整往返成交后的严重亏损；
- 条件净收益均值和下行分位；
- 同日 14:30 横截面相对收益。

## 架构

### 第一层：因果基础评分器

两个训练窗口分别覆盖 252 和 504 个交易日。每个窗口训练入场成交、条件退出、
正收益、严重亏损、条件收益、下行分位和横截面排序模型。所有特征只允许使用
14:30 及以前信息。

### 第二层：元模型

元模型使用严格外层样本外的第一层输出，而不是第一层训练内拟合值。它学习：

- `meta_p_positive`
- `meta_expected_net_return_pct`
- `meta_p_severe_loss`
- `meta_rank_pct`
- `meta_score`

训练窗口 126 日，之后净空 2 日，再用 21 日校准。

### 第三层：退出失败风险

独立模型估计已入场后 T+1 退出失败风险，并在同日同槽计算风险排名。
训练窗口 126 日，净空 2 日，校准窗口 42 日。

### 第四层：冻结政策

V40 使用来自 V15 研究的冻结门槛：

| 门槛 | 固定值 |
| --- | ---: |
| 元模型正收益概率 | `>= 0.54` |
| 元模型期望净收益 | `>= 0.00%` |
| 严重亏损概率 | `<= 0.35` |
| 完整往返成交概率下界 | `>= 0.95` |
| 元模型横截面排名 | `>= 0.95` |
| 退出失败风险排名 | `<= 0.50` |

这些门槛不会在 2026 年 5–7 月回测结果上重新搜索。固定 14:30 和双队列规则
构成 V40 新合同，因此旧 V15 表现只作为研究来源披露。

## 因果特征

- 14:00–14:30 趋势、回撤、反弹、波动和价格效率；
- 5 分钟实体、振幅、上下影线、成交额和量价结构；
- 严格滞后的日频动量、波动、回撤、换手、估值和规模；
- 当时市场和申万一级行业收益、广度、离散度和相对强弱；
- 同日 14:30 横截面分位；
- 基础模型严格样本外概率、收益、风险及不确定性。

禁止使用当日收盘后数据、T+1 数据、未来高低价、盘后榜单和人工选择结果。

## 训练和校准

- 历史因果面板：2021-07-26 至 2026-07-31。
- 正式滚动样本外窗口：2023-07-27 至 2026-07-31。
- 2026-05 至 2026-07 为用户指定回测展示区间。
- 每个外层折只用测试期之前的历史训练和校准。
- 模型最终包使用截至 2026-07-31 已有标签的数据；2026-07-31 的未来真值
  不参与训练。

模型包绑定：

- 训练数据摘要；
- 基础模型指纹；
- 元模型和退出风险模型；
- 固定门槛；
- 特征版本；
- 完整策略合同指纹。

## 已知限制

- V15 正向结果样本较小且年度不稳定，不能直接证明 V40 盈利。
- 14:30 固定时点牺牲了跨时点机会，换取更清晰的人工操作和可复现实验单元。
- 标准观察是门槛诊断样本，不代表可买。
- A 股涨跌停、停牌和成交拥堵会使模型概率与真实可成交结果偏离。
- 任何历史正收益都必须经过至少 150 个未来交易日的精确模型影子验证。

## 适用状态

V40 初始状态只能是 `SHADOW_OBSERVATION` 或 `SHADOW`。历史门槛、未来影子
门槛和完整性门槛全部通过前，`production_authorized` 必须保持 `false`。
