# WP V41 模型卡

## 用途

WP V41 在每个 A 股交易日 14:00 对主板可交易股票评分，输出全部固定门槛合格
票和 5 支独立观察票。它服务人工决策，不自动交易。

## 预测目标

主要目标是固定 14:05 影子入场、T+1 收盘退出、扣除 10bp 入场滑点和 25bp
往返成本后的 `net_return_pct > 0`。

辅助模型分别估计入场成交、T+1 退出、条件正收益、严重亏损、条件收益均值、
下行分位和同日 14:00 横截面相对收益。

## 模型结构

1. 两个因果基础模型窗口分别覆盖 252 和 504 个交易日。
2. 元模型只学习严格外层样本外基础预测，训练 126 日、净空 2 日、校准 21 日。
3. 退出失败风险模型训练 252 日、净空 2 日、校准 42 日。
4. 冻结政策同时检查概率、期望收益、严重亏损、往返成交、横截面排名和退出风险。

## 因果特征

- 13:30–14:00 趋势、回撤、反弹、波动和价格效率；
- 五分钟实体、振幅、影线、成交额和量价结构；
- 严格滞后的日频动量、波动、回撤、换手、估值和规模；
- 当时市场与行业收益、广度、离散度和相对强弱；
- 同日 14:00 横截面分位；
- 基础模型严格样本外概率、收益、风险和不确定性。

禁止使用 14:00 后信息决定候选，也禁止使用 T+1 数据、盘后榜单和人工选择结果。

## 固定门槛

V41 初始冻结门槛沿用已研究的结构先验，但必须在 14:00 新合同下重新评估：

| 门槛 | 固定值 |
| --- | ---: |
| 元模型正收益概率 | `>= 0.54` |
| 元模型期望净收益 | `>= 0.00%` |
| 严重亏损概率 | `<= 0.35` |
| 完整往返成交概率下界 | `>= 0.95` |
| 元模型横截面排名 | `>= 0.95` |
| 退出失败风险排名 | `<= 0.50` |

这些数值不是盈利证明。V41 的生产资格只能来自新合同回测和至少 150 个交易日的
未来影子验证。

## 已知限制

- 决策提前 30 分钟会改变特征、价格和候选分布，V40 结果不能迁移。
- 观察票是门槛诊断样本，不代表可买。
- 涨跌停、停牌和成交拥堵会使估计概率与真实执行偏离。
- 模型在全部晋级门槛通过前只能处于影子状态。
