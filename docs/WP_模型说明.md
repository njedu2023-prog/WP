# WP 模型说明

## 唯一预测目标

正式模型预测：

```text
P(T+1_close_net_return > 0 | T日14:20-14:55之前可获得的信息)
```

其中：

```text
gross_return = T+1_close / signal_price - 1
net_return   = gross_return - round_trip_cost
```

`signal_price` 在正式 `BUY` 锁定时写入不可变账本。验证不得使用盘后价格、下一次刷新价格或重新挑选后的候选价格。

## 三层结构

### 1. 研究候选生成

`wp_rule_v2_1`、`ranking_score`、`p_limitup_t1` 和 `tail_profit_v1` 继续用于流动性过滤、特征解释和候选压缩。它们不是经过成本后 T+1 净收益训练的正式模型，因此：

- 不直接产生 `BUY`；
- 不进入正式策略收益；
- 收盘日线代理样本权重固定为 0，不能提高实盘置信度。

### 2. 成本后概率估计

`t1_net_profit_probability_v2` 只使用已验证的合法尾盘因果样本，并按候选特征相似度加权：

- 当前涨幅；
- 旧候选质量分；
- 风险惩罚分；
- 5 日成交额放大；
- 板块一致性。

模型输出：

- 成本后盈利概率；
- 95% 单侧 Wilson 下界；
- 期望净收益；
- T+1 开盘、最高、最低、收盘分位数；
- 10% 下行分位；
- 有效样本量、真实样本数和独立交易日数。

同一交易日多只股票高度相关，因此概率置信样本量不超过独立交易日数，防止把同日横截面误当成独立证据。

### 3. 可执行决策

`t1_net_profit_decision_v3` 按保守盈利概率下界排序，并要求同时满足：

- 市场状态允许；
- 数据年龄不超过 120 秒；
- 至少 30 个真实样本；
- 至少 30 个独立交易日；
- 有效样本量至少 15；
- 成本后盈利概率至少 58%；
- 95% 单侧下界至少 50%；
- 期望净收益至少 0.30%；
- 10% 下行分位不低于 -4.50%；
- 连续合格和连续领先均达到配置门槛。

只有 14:45-14:54 期间全部通过，才锁定当天唯一 `BUY`。14:55 后禁止新开仓。

## 统计口径

正式绩效只读取 `wp_strategy_ledger`：

- 决策日包括 `BUY` 与 `NO_TRADE`；
- 交易胜率只统计已经取得 T+1 真值的 `BUY`；
- 盈亏使用扣费后的 `net_return`；
- 同一天最多一笔；
- 计算平均、中央净收益、复合累计净收益与最大回撤；
- 历史研究表和正式策略表分开展示。

永久 `NO_TRADE` 会形成没有经济价值的虚假高胜率，因此系统同时报告交易覆盖率和交易日数。门槛调整只能依据滚动、严格时序的样本外验证，不能为了增加名单数量人工放宽。

## 当前证据状态

当前真实因果样本仍少于正式门槛，系统应输出 `WATCH` 或 `NO_TRADE`，而不是伪造高置信度。收盘日线代理回测只验证工程链路，不能证明 14:20 后策略可盈利。

后续提升模型的首要工作不是增加规则，而是持续积累合法分钟级快照和 T+1 真值，再进行按交易日分组的滚动样本外训练、校准和门槛选择。
