# WP V3 模型卡

## 任务

二分类目标是固定交易合同下 `net_return_pct > 0`。模型不预测涨停，也不优化排行榜分数。回归辅助目标是同一合同的净收益均值和 10% 下行分位。

## 特征

全部特征在信号时点可观测：

- 当前路径：相对昨收、相对开盘、5/10/20 分钟收益；
- 尾盘结构：10 分钟振幅、收盘位置、成交额加速度；
- 可执行性：价格、涨跌停距离、当前成交额、20 日平均成交额；
- 前序日线：1/2/5/10/20 日收益、20 日波动、5 日振幅；
- 规模与流动性：前日换手率、流通市值、总市值；
- 市场状态：全市场收益中位数、上涨家数比例、尾盘收益、涨跌停数量；
- 行业状态：行业收益中位数和上涨比例；
- 时间：距 14:20 的分钟数。

模型特征由固定白名单控制。名称包含 `next_`、`t1_`、`future_`、`target`、`net_return` 等字段不能注册为模型特征。

## 模型结构

每个时间窗口训练两个分类器：

1. 中位数填补、稳健缩放、L2 正则逻辑回归；
2. 中位数填补、浅叶节点、L2 正则的 HistGradientBoosting。

窗口为最近 252、504、756 个训练交易日。窗口内两个模型按 45%/55% 集成，窗口间等权。

另训练：

- HistGradientBoosting 均值回归器；
- `loss=quantile, quantile=0.10` 的下行回归器。

## 概率校准与不确定性

- 最后 21 个训练交易日只用于时间外 Platt 校准。
- 校准前留 2 个交易日 purge，避免 T+1 标签边界重叠。
- 模型间预测的 10% 分位作为保守概率下界。
- 模型间标准差是稳定性门槛。
- 校准样本按预测概率分箱，逐箱记录样本数、独立交易日、真实胜率、95% Wilson
  下界和按交易日整簇 bootstrap 的 95% 下界。

逐票必须同时通过模型概率、模型下界、两类经验下界、最少分箱样本数和最少
独立交易日。

## 默认资格门槛

| 门槛 | 默认值 |
| --- | ---: |
| 校准净盈利概率 | ≥ 60% |
| 模型间保守下界 | ≥ 52% |
| 校准分箱样本 | ≥ 100 |
| 校准分箱交易日 | ≥ 10 |
| 分箱 Wilson 下界 | ≥ 52% |
| 分箱按日聚类下界 | ≥ 50% |
| 期望净收益 | ≥ 0.30% |
| 下行 10% 分位 | ≥ -4.50% |
| 模型概率标准差 | ≤ 0.10 |
| 行情年龄 | ≤ 420 秒 |

阈值写入模型登记册。不得在看到测试集结果后无记录地反复修改。

## 已知限制

- 参考订单为 10 万元，不代表任意资金规模均可按同样滑点成交。
- Tushare 5 分钟成交额无法还原逐笔排队位置；涨跌停距离和容量门槛是保守近似。
- T+1 收盘固定退出不一定是收益最大化退出，但它使标签可执行、唯一且不可事后挑选。
- 申万一级行业按 `in_date/out_date` 在每个历史交易日还原，不使用当前行业倒填。
- 分时数据只能近似成交队列；单票条延迟和全市场覆盖率门槛只能拒绝明显坏数据，
  不能替代交易所逐笔数据。
- 三年回测不能证明未来盈利，因此生产晋级还要求 150 个交易日前瞻影子样本。
