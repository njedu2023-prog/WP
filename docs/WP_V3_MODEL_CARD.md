# WP V9 模型卡

## 唯一任务

系统只估计并筛选这一条完整交易合同：

```text
T 日 14:20-14:50 首次出现信号
-> 下一根真实 5 分钟线可成交买入
-> T+1 收盘集合竞价可退出
-> 扣除滑点与往返成本后的净收益 > 0
```

系统不预测涨停、不使用未来最高价、不优化名单数量。没有股票通过门槛时，
`NO_SIGNAL` 是正式结果。

## 标签与收益合同

对每个 `trade_date x signal_slot x ts_code` 定义：

- `E`：下一根 5 分钟线满足价格、涨停距离、成交额和容量约束；
- `X`：已入场后可在固定 T+1 收盘合同退出；
- `R_cond`：`E=1, X=1` 时的扣费后净收益；
- `R_all`：完整执行结果。

```text
E=1, X=1  -> R_all = R_cond
E=0       -> R_all = 0，正收益标签为失败
E=1, X=0  -> R_all = -10%，表示退出失败惩罚
```

正收益主标签为 `1[E=1 and X=1 and R_cond>0]`。入场未成交不是虚构亏损，
但也不能计为策略盈利。

## Point-in-time 特征

历史与实时共用同一特征白名单：

- 盘中：相对昨收和开盘收益、5/10/20 分钟动量、区间振幅、影线、VWAP
  偏离、波动、回撤、趋势效率、14:00 后累计成交额及成交额加速度；
- 日频：严格滞后一日的 1/2/3/5/10/20 日复权收益、波动、下行波动、
  成交额、换手率、量比、估值和规模；
- 市场与行业：市场收益和广度、行业收益和广度、个股相对市场和行业强弱；
- 横截面：同日同槽内的动量、流动性、波动、规模、尾盘效率和涨停距离分位。

白名单拒绝含 `next_`、`t1_`、`future_`、`target`、`net_return`、
`exit_price` 或 `truth_` 的字段。未来 K 线追加测试必须证明历史特征不变。

## V9 hurdle 集成

使用 252 日与 504 日两个确定性训练窗口。每个成员训练：

1. `P(E)` 入场成交分类器；
2. `P(X|E)` 固定退出可成交分类器；
3. `P(R_cond>0|E,X)` 完成往返后的正收益分类器；
4. `P(R_cond<=-2%|E,X)` 条件严重亏损分类器；
5. `E[R_cond|E,X]` 条件收益 L1 回归器；
6. `Q10[R_cond|E,X]` 条件收益 10% 分位回归器；
7. 完成往返后进入同槽收益前 20% 的分类器；
8. 以条件净收益横截面分位为目标的 LambdaRank；
9. 直接全路径正收益、严重亏损、均值与 Q10 模型，仅作独立审计。

主概率不使用直接全路径分类器：

```text
P(net_profit) = P(E) * P(X|E) * P(R_cond>0|E,X)
```

主期望收益为：

```text
EU = P(E) * [
       P(X|E) * E(R_cond|E,X)
       + (1-P(X|E)) * exit_failure_penalty
     ]
```

严重亏损概率按以下分解计算，并与直接全路径严重亏损模型取更保守者：

```text
P(severe) = P(E) * [
  1-P(X|E) + P(X|E)*P(R_cond<=-2%|E,X)
]
```

直接全路径模型输出保存为审计列，不参与主候选排序或授权。

## 校准与保守下界

- 入场、退出、条件正收益、条件严重亏损、横截面领先以及直接审计概率，
  分别使用严格早于测试期的 42 日 Beta calibration；
- `p_net_positive_lower` 使用两个时间窗口因子化概率的 10% 集成分位；
- `expected_utility_lower_pct` 等于当前因子化期望，加上历史校准期
  `实际 R_all - 预测 EU` 的同槽 10% 残差；
- 槽内样本不足时只允许回退到全局残差下界；
- 残差调整强制不大于 0，因此“保守下界”永远不能高于点估计。

## 候选排序

成交概率是硬门槛，不参与软排序。每个集成成员先在同日同槽内计算分位：

```text
35% 因子化期望收益分位
+ 25% 条件期望收益分位
+ 20% 条件正收益概率分位
+ 15% 条件收益 LambdaRank 分位
+  5% 严重亏损安全分位
```

成员选择分的均值形成 `selection_score`，成员间标准差形成稳定性门槛。

## 政策选择与样本外边界

每个滚动折只可使用更早的数据：

1. 训练和校准完成后，对测试期产生一次性 OOS 预测；
2. 候选门槛只在更早的 84 个 OOS 交易日设计；
3. 设计期只选一个冠军；
4. 冻结冠军后，只在后续 42 个 OOS 交易日确认一次；
5. 确认失败不得查看结果后改试其他门槛，该折输出 `NO_SIGNAL`。

最终报告覆盖完整三年滚动 OOS。任何全局回填、未来感知切分或在确认期反复
试政策都属于协议违规。

## 生产晋级

三年 OOS 必须同时满足候选数、交易日、胜率及置信下界、按日聚类下界、
平均和中位净收益、Profit Factor、入场/退出成交率、概率校准和 50bp
压力测试。通过后仍只能进入影子状态。

精确模型指纹必须再完成至少 150 个未来交易日、50 个候选日和 250 个候选的
影子验证。模型、特征、政策或交易合同变化后，影子计数归零。

## 已知限制

- 5 分钟 K 线不能完整还原盘口排队、逐笔冲击和人工下单延迟；
- 10 万元参考订单与 1% 槽成交额上限不代表任意资金容量；
- 固定 T+1 收盘退出不是事后最优路径，但它唯一、可执行且可审计；
- 统计通过只能证明历史和影子证据达到合同门槛，不能保证未来盈利；
- 任一门槛不通过时，系统必须保持研究观察或零候选，不能降低标准。
