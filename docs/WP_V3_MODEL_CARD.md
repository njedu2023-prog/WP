# WP V4 模型卡

## 任务

绝对目标是固定交易合同下 `net_return_pct > 0`。辅助目标是同一合同的净收益
横截面分位、稳健条件均值和 10% 下行分位。模型不预测涨停，也不优化页面排名。

## 因果特征

所有特征在对应信号槽已经可观测，并由历史和实时共用代码生成。

### 14:00 至当前槽

- 相对昨收、相对开盘、5/10/20 分钟收益和 14:00 后累计收益；
- 当前 K 线实体、振幅、上影线和下影线；
- 累计高低区间、区间收盘位置、金额加权价格偏离；
- 已实现波动、平均绝对收益、上涨/下跌 K 线占比；
- 有符号价格效率、对数价格趋势斜率和拟合优度；
- 最大回撤、低点反弹、累计成交额、最新成交额占比和成交额集中度。

### 严格滞后的日频状态

- 前一日缺口、日内收益、收盘位置和影线；
- 1/2/3/5/10/20 日复权收益；
- 5/10/20 日上涨占比、波动、下行波动和距 20 日高点回撤；
- 成交额水平与加速度、换手率与换手加速度、量比、PE、PB、流通和总市值。

### 横截面与环境

- 市场收益、上涨广度、超过 2%/5% 的广度、离散度和尾盘广度；
- 申万一级行业收益、广度和尾盘状态，成分按历史有效区间还原；
- 股票相对市场、相对行业的强弱；
- 同一 `trade_date × signal_slot` 内的动量、流动性、波动、规模、尾盘效率和
  涨停距离分位。

特征白名单拒绝名称含 `next_`、`t1_`、`future_`、`target`、`net_return`、
`exit_price` 或 `truth_` 的字段。14:20 特征的单元测试会追加极端 14:25 数据并
验证结果完全不变。

## 数据对称性

历史端分页获取真实 `stk_mins(freq=5min)`，在计算当日开盘后只保留
14:00-14:50 的暖机和信号 K 线。实时端按主板代码分批调用 `rt_min(freq=5MIN)`，
每个槽写入不可变会话快照；`rt_k` 只提供当日开盘和权威昨收。盘中高低价、
成交量和成交额不使用可能越过信号槽的日累计快照。

全市场分钟覆盖低于 90%、当前条晚于目标槽超过 5 分钟、行情年龄超过 420 秒或
14:20 时少于 5 根连续快照时失败关闭。

## 模型结构

训练窗口为最近 126、252、504 个拟合交易日。每个窗口训练两个模型：

1. HistGradientBoosting 二分类器，估计固定成本后正净收益概率；
2. HistGradientBoosting 回归器，学习每个交易日、每个信号槽内的净收益分位。

另在拟合样本上训练稳健绝对损失收益回归器和 `quantile=0.10` 下行回归器。
拟合样本按稳定、无标签哈希在每个 `trade_date × signal_slot` 最多保留 300 行；
校准、政策证据、外层测试和最终统计保留全量。

选择分固定为：

```text
0.40 × 横截面排序模型分位
+ 0.25 × 期望净收益分位
+ 0.20 × 正净收益概率分位
+ 0.15 × 下行 Q10 分位
```

权重属于政策合同，不能查看测试结果后静默修改。

## 时间隔离

- 外层测试块固定 42 个交易日。
- 每折训练数据与测试块之间 purge 2 个交易日。
- 内层最近 84 日不参与基础模型拟合。
- 内层前 42 日只拟合 Platt 概率校准。
- 内层后 42 日只形成候选策略证据。
- 策略证据按“首次通过”口径统计候选，不能使用概率粗分箱代替选择队列证据。

## 默认候选门槛

| 门槛 | 默认值 |
| --- | ---: |
| 校准正净收益概率 | >= 55% |
| 时间窗口保守概率下界 | >= 50% |
| 同槽选择分位 | >= 99.7% |
| 期望净收益 | >= 0.20% |
| 下行 10% 分位 | >= -3.50% |
| 概率模型标准差 | <= 0.12 |
| 排序模型分位标准差 | <= 0.20 |
| 独立证据候选 | >= 250 |
| 独立证据候选日 | >= 25 |
| 证据 Wilson 下界 | >= 52% |
| 证据按日聚类胜率下界 | >= 50% |
| 证据平均净收益及其按日聚类下界 | > 0 / >= 0 |
| 连续盘中快照 | >= 5 |
| 行情年龄 | <= 420 秒 |

若独立证据期不满足任一门槛，整个冻结模型只能观察，不发布合格候选。

## 已知限制

- 5 分钟 K 线无法还原盘口排队和逐笔冲击，10 万元参考订单只是一致的容量合同。
- T+1 收盘退出不是事后最优退出，但它唯一、可执行并能避免路径挑选。
- 三年历史可能包含制度和风格漂移，故外层按时间测试并另要求 150 个未来交易日。
- 提升特征数量不能保证存在经济优势；若真实样本外门槛不通过，正确输出是
  `SHADOW_OBSERVATION` 或零候选，而不是调低标准。
