# WP V40 不可变策略合同

## 1. 唯一目标

固定标签为：

```text
Y = 1[
  entry_fillable
  AND exit_fillable
  AND (
    adjusted_T+1_close
    / (14:35_close * (1 + 10bp_slippage))
    - 1
    - 25bp_round_trip_cost
  ) > 0
]
```

系统优化的是执行完整交易合同后的正净收益概率，不是涨停概率、当日排名、
未来最高价或未经成本调整的收益。

## 2. 时间状态机

| 北京时间 | 状态 | 允许行为 |
| --- | --- | --- |
| 14:00–14:25 | `PRE_SIGNAL` | 采集暖机快照，不发布候选 |
| 14:30 | `SIGNAL` | 使用刚完成的 14:30 五分钟线形成唯一当日决策 |
| 14:30–14:35 | `NO_NEW_SIGNAL` | 保持原决策，等待独立入场基准 |
| 14:35 | `SETTLEMENT` | 锁定 14:35 五分钟线参考成交价 |
| 14:40–15:00 | `FROZEN` | 冻结合格与观察台账，不得新增或替换 |
| 15:00 后 | `CLOSED` | 可买展示必须为 0，只保留历史记录和待验证状态 |

只有 `14:30` 是合法决策时点。盘后运行不得补造候选；14:35、14:40 和
15:00 的运行只完成入场结算、冻结和页面状态切换。

## 3. 股票池和可执行性

- 范围为 A 股主板。
- 排除 ST、停牌、上市不足 60 日的股票。
- 价格必须在 2–150 元。
- 前 20 日平均成交额至少 5,000 万元。
- 14:30 和 14:35 五分钟成交额至少 300 万元。
- 参考订单为 10 万元，且不超过对应五分钟成交额的 1%。
- 14:30 信号价距离涨停至少 0.50%，距离跌停至少 1.00%。
- 14:35 入场基准同样必须距离涨停至少 0.50%。
- 14:30 前必须存在至少 5 个真实尾盘快照。
- 数据年龄不得超过 420 秒；主板分钟覆盖率不得低于 90%。

不满足上述任一硬约束的股票既不能进入合格候选，也不能进入标准观察。

## 4. 双队列合同

### 合格候选

所有同时通过以下固定门槛的股票全部发布，数量不设人为上限：

- 元模型正净收益概率；
- 元模型期望净收益；
- 严重亏损概率；
- 完整往返成交概率；
- 同时点横截面排名；
- T+1 退出失败风险排名；
- 实时数据新鲜度和可执行性。

当天可以 0 支。零候选是合法策略结果，不能触发降门槛或强行 Top N。

### 标准观察

从“硬可执行但未完全合格”的股票中，按以下固定顺序选最多 5 支：

1. 失败软门槛数量更少；
2. 离固定门槛的总距离更小；
3. 元模型综合分更高；
4. 股票代码升序作为确定性平局规则。

正常数据条件下必须恰好 5 支。少于 5 支表示真实可用股票池不足或数据故障，
必须报告完整性异常，不得放宽硬约束、引入合格票或重复股票补位。

合格与观察不得重叠。标准观察只用于独立研究统计，不是推荐，也不能与正式策略
样本合并。

## 5. 不可变字段

唯一键：

```text
(strategy_id, trade_date, candidate_cohort, ts_code)
```

14:30 首次写入后锁定：

- `signal_slot`
- `first_signal_time`
- `first_signal_price`
- `candidate_cohort`
- `model_version`
- `model_fingerprint`
- `policy_fingerprint`
- `feature_version`
- `target_trade_date`
- `entry_contract`
- `exit_contract`
- 成本、滑点及非成交惩罚参数

14:35 只允许一次性补充：

- `entry_benchmark_slot`
- `entry_benchmark_price`
- `entry_price`
- `entry_fillable`
- `entry_benchmark_status`

重复运行必须幂等。后续刷新不得替换股票、队列、信号价、入场价、模型版本或
目标交易日。

## 6. T+1 真值

- `target_trade_date` 必须由 A 股交易日历计算，不按自然日推断。
- T+1 14:57 提交跌停价限价卖单参加收盘集合竞价，统计价为收盘撮合价。
- 使用 T 日和 T+1 的复权因子计算总回报；任一复权因子缺失时保持待验证。
- 入场未成交时净收益为 0，标签为失败。
- 已入场但 T+1 无成交，或收盘仍封死跌停，按 `-10.00%` 退出失败惩罚。
- 成功退出时从总回报中扣除固定 25bp 往返成本。
- 50bp 压力测试在基准 35bp 全成本上额外扣除 15bp。

严禁使用盘后生成价、后续刷新价、人工实际成交价、T+1 最高价或其他未来路径
改写模型真值。

## 7. 证据隔离

- 历史回测：2026-05-01 至 2026-07-31 请求区间，实际按交易日历取样。
- 真实影子：从 2026-08-03 起，且必须发生在模型训练完成之后。
- 合格候选与标准观察分别统计。
- 历史回测与未来影子分别统计。
- 用户实际交易不进入模型台账。
- V15 仅提供冻结门槛来源，不继承其历史收益或影子时钟。

任何模型、特征、门槛、时点、执行价格或成本合同变化都产生新指纹，并从第 0
个未来影子交易日重新累计。
