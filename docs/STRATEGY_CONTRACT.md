# WP 正式策略合同

## 唯一目标

生产优化量是：

```text
P(T+1 固定退出后的净收益 > 0 | T 日 14:20-15:00 前可观测信息)
```

净收益必须扣除配置中的往返成本。排名分、涨停概率、报告数量和页面更新次数都不是最终目标。

## 时间与可成交性

| 北京时间 | 状态 | 允许行为 |
| --- | --- | --- |
| 14:20-14:44 | `WATCH` | 采集快照、更新研究候选 |
| 14:45-14:54 | `BUY/WATCH` | 门槛全部通过时锁定唯一正式买入 |
| 14:55-14:59 | `LOCKED/NO_TRADE` | 只展示已锁定决定；禁止新开仓 |
| 15:00 以后 | `CLOSED` | 禁止生成或修改买入名单 |

正式 `BUY` 必须包含行情时间、发布时刻、股票、参考买价、模型版本、样本量、概率、概率下界、期望净收益和退出合同。一个交易日只允许一条不可变正式记录。

## 数据分层

1. 生产因果数据：当时真实可见的尾盘快照，可参与训练、校准和正式决策。
2. 研究代理数据：收盘日线重建，只能用于假设探索，不得授权交易。
3. T+1 真值：交易日历解析后的下一交易日真实收盘价。
4. 缺失数据：明确记录为 `missing/invalid_post_close`，不得用盘后名单回填。

所有特征必须带可用时间。任何在决策时刻尚不可获得的数据都视为未来信息。

## 决策门槛

当前生产门槛由 `config/wp_config.yml` 控制：

- 真实尾盘样本不少于 30，且覆盖不少于 30 个独立交易日；
- 有效加权样本不少于 15；
- 成本后盈利概率不少于 58%；
- 单侧 95% Wilson 下界不少于 50%；
- 成本后期望收益不少于 0.30%；
- 下行 10% 分位不低于 -4.50%；
- 候选连续合格、连续领先均达到要求；
- 行情、市场状态、流动性和数据新鲜度全部合格。

门槛不是盈利证明。达到门槛只允许小样本前向观察，不能替代样本外检验。

## 验证与晋级

正式统计只读取不可变策略账本，且按时间顺序计算：

- 净盈利率及 Wilson 下界；
- 平均、 中位数和累计净收益；
- 最大回撤；
- `BUY` 与 `NO_TRADE` 天数；
- 按市场状态、时间槽和流动性分层的稳定性。

研究模型晋级生产前，至少需要预注册的滚动样本外评估、交易成本敏感性测试、成交可行性检查和足够的独立交易日。不能用同一批数据同时选规则、调阈值和宣称有效。
