# WP V41 不可变策略合同

## 1. 唯一目标

固定标签为：

```text
Y = 1[
  entry_fillable
  AND exit_fillable
  AND (
    adjusted_T+1_close
    / (14:05_close * (1 + 10bp_slippage))
    - 1
    - 25bp_round_trip_cost
  ) > 0
]
```

系统优化执行完整交易合同后的正净收益概率，不优化涨停概率、未来最高价或未经
成本调整的收益。

## 2. 时间状态机

| 北京时间 | 状态 | 允许行为 |
| --- | --- | --- |
| 13:30–13:55 | `PRE_SIGNAL` | 每 5 分钟采集因果暖机快照，不发布候选 |
| 14:00 | `SIGNAL` | 使用刚完成的 14:00 五分钟线形成唯一当日决策 |
| 14:00–14:05 | `NO_NEW_SIGNAL` | 保持原决策，等待独立入场基准 |
| 14:05 | `SETTLEMENT` | 锁定 14:05 五分钟线参考成交价 |
| 14:10–15:00 | `FROZEN` | 冻结合格与观察台账，不得新增或替换 |
| 15:00 后 | `CLOSED` | 可买展示必须为 0，只保留历史和待验证状态 |

只有 `14:00` 是合法决策时点。盘后运行不得补造可交易候选；14:05、14:10
和 15:00 的运行只完成入场结算、冻结和页面状态切换。

## 3. 股票池和可执行性

- 范围为 A 股主板。
- 排除 ST、停牌、上市不足 60 日的股票。
- 价格必须在 2–150 元。
- 前 20 日平均成交额至少 5,000 万元。
- 14:00 和 14:05 五分钟成交额至少 300 万元。
- 参考订单为 10 万元，且不超过对应五分钟成交额的 1%。
- 14:00 信号价距离涨停至少 0.50%，距离跌停至少 1.00%。
- 14:05 入场基准同样必须距离涨停至少 0.50%。
- 14:00 前必须存在至少 5 个真实暖机快照。
- 数据年龄不得超过 420 秒；主板分钟覆盖率不得低于 90%。

不满足任一硬约束的股票既不能进入合格，也不能进入观察。

## 4. 双队列合同

### 合格

所有同时通过盈利概率、期望净收益、严重亏损、往返成交、横截面排名、退出风险、
数据新鲜度和可执行性门槛的股票全部发布，数量不设人为上限。当天可以 0 支，
不能降门槛或强行 Top N。

### 观察

从“硬可执行但未完全合格”的股票中，按失败门槛数量、门槛距离、模型分数和股票
代码的固定顺序选最多 5 支。正常数据条件下必须恰好 5 支；少于 5 支表示股票池
或数据完整性异常，不得补位。

合格与观察不得重叠。观察只用于独立研究统计，不是推荐。

## 5. 不可变字段

唯一键：

```text
(strategy_id, trade_date, candidate_cohort, ts_code)
```

14:00 首次写入后锁定：

- `signal_slot`
- `first_signal_time`
- `first_signal_price`
- `candidate_cohort`
- `model_version`
- `model_fingerprint`
- `policy_fingerprint`
- `feature_version`
- `target_trade_date`
- 执行合同、成本、滑点和非成交惩罚参数

14:05 只允许一次性补充入场基准时点、基准价、影子入场价和成交状态。重复运行
必须幂等；后续刷新不得替换股票、队列、价格、模型版本或目标交易日。

## 6. T+1 真值

- `target_trade_date` 必须由 A 股交易日历计算。
- T+1 14:57 提交跌停价限价卖单参加收盘集合竞价，以收盘撮合价结算。
- 使用 T 日和 T+1 复权因子计算总回报；缺失时保持待验证。
- 入场未成交时净收益为 0，标签为失败。
- 已入场但 T+1 无成交或收盘封死跌停，固定记 `-10.00%`。
- 成功退出时从总回报扣除固定 25bp 往返成本。
- 50bp 压力测试在 35bp 基准全成本上额外扣除 15bp。

严禁使用盘后生成价、后续刷新价、人工成交价、T+1 最高价或其他未来路径改写真值。

## 7. 证据隔离

- V41 历史回测必须按 14:00/14:05 新合同重新生成。
- V41 真实影子从 `2026-08-05` 起。
- 合格和观察分别统计；历史回测和未来影子分别统计。
- 旧 V15/V40 只保留审计，不能继承收益、模型状态或影子时钟。
- 用户实际交易不进入模型台账。

任何模型、特征、门槛、时点、执行价格或成本合同变化都产生新指纹，并从第 0 个
未来影子交易日重新累计。
