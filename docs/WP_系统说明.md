# WP V40 系统说明

## 人话版

每天 14:30，系统只做一次正式筛选：

1. 把当时主板所有可交易股票放进同一模型。
2. 通过全部固定门槛的股票全部放进“合格候选”，可能一支也没有。
3. 再从没有合格、但确实可交易的股票中选出最接近门槛的 5 支，放进
   “标准观察”。
4. 14:35 用真实完成的五分钟线记录统一参考买入价。
5. 下一交易日收盘后，用真实收盘价验证每一支股票。

人工只看系统结果并自行决定是否买入。系统不记录人工买了哪支，也不会把人工
结果混进模型统计。

## 为什么不是强制 5 支推荐

强制推荐 5 支会在没有好机会时把差股票包装成机会。V40 的合格候选数量完全由
固定门槛决定，可以是 0、1、5 或更多。

固定 5 支的是“标准观察”，不是推荐。它让系统每天都有一组稳定对照，用于验证：

- 合格门槛是否真的筛掉了更差的股票；
- 哪个门槛过严或过松；
- 模型失效时，合格与观察的结果是否开始接近或反转。

## 页面怎么看

- **合格候选**：通过全部门槛，人工可以进一步判断。
- **标准观察**：只研究、不代表合格，页面会显示未通过原因。
- **今日状态**：显示等待 14:30、已生成、已冻结或窗口关闭。
- **真实验证**：逐票显示 14:30 信号、14:35 参考入场和 T+1 收盘净收益。
- **历史回测**：只显示 2026 年 5–7 月严格样本外结果。
- **8 月影子**：只累计 2026-08-03 之后、由冻结 V40 模型真实产生的记录。

15:00 后页面不再展示“可以买”的名单，但历史台账和待验证记录仍可查看。

## 系统不会做的事

- 不自动下单；
- 不记录用户是否买入；
- 不为了产生名单降低门槛；
- 不用盘后价格补造 14:30 候选；
- 不把标准观察混入合格候选业绩；
- 不把历史回测当成未来盈利保证；
- 不把 V15 的旧收益直接算成 V40 收益。

## 当前证据顺序

1. 完成 2026 年 5、6、7 月固定 14:30 回测。
2. 2026-08-03 收盘后补齐 2026-07-31 的最后一批 T+1 真值。
3. 从 2026-08-03 开始真实影子统计。
4. 至少运行 150 个未来交易日，并达到候选数量、收益、胜率、置信区间、
   成交率和压力测试要求。

没有完成以上步骤前，系统只能作为研究型人工决策支持，不能宣称已经能稳定盈利。
